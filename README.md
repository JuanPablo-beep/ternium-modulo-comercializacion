# Proyecto de mejora del módulo de Comercialización de Ternium Argentina

## Descripción del proyecto

Este proyecto académico propone mejorar el módulo de Comercialización de Ternium Argentina, con el objetivo de optimizar la gestión de pedidos, la consulta de disponibilidad de productos y la coordinación de las fechas de entrega.

La propuesta busca mejorar la organización de la información y la comunicación entre las áreas involucradas, contribuyendo a reducir errores y facilitar el seguimiento de los pedidos.

## Objetivo general

Desarrollar una propuesta de mejora del módulo de Comercialización que permita centralizar la información de los pedidos, consultar la disponibilidad de productos y coordinar las fechas de entrega de manera más eficiente.

## Declaración de Uso de Inteligencia Artificial

Durante la elaboración de este proyecto se utilizaron herramientas de inteligencia artificial como apoyo para organizar y revisar distintos contenidos del trabajo práctico. Su utilización tuvo como objetivo la mejora de redacción así como también la realización de diagramas relacionados con la propuesta de mejora del módulo de Comercialización de Ternium Argentina.

Entre los principales prompts utilizados se encontraron instrucciones orientadas a:
* Elaboración de diagrama de Gantt.
* Elaboración de diagrama jerárquico.
* Elaboración de tablas.
* Construcción del diagrama BPMN para el flujo de comercialización, detallando la interacción entre áreas, puntos de control y manejo de desvíos operativos.
* Obtener orientación para documentar el proyecto utilizando Git y GitHub.

Los resultados proporcionados por las herramientas de inteligencia artificial no fueron considerados respuestas definitivas ni se incorporaron automáticamente al trabajo. Se realizaron revisiones para comprobar que los contenidos fueran coherentes con las consignas, con el proyecto desarrollado y con los conocimientos adquiridos durante la cursada.

Asimismo, se revisaron las sugerencias generadas por la inteligencia artificial para evitar inconsistencias o repeticiones que no se correspondieran con el proyecto.

En conclusión, la inteligencia artificial fue utilizada como una herramienta complementaria de asistencia.
