# Proyecto de mejora del módulo de Comercialización de Ternium Argentina

## Descripción del proyecto

Este proyecto académico propone mejorar el módulo de Comercialización de Ternium Argentina, con el objetivo de optimizar la gestión de pedidos, la consulta de disponibilidad de productos y la coordinación de las fechas de entrega.

La propuesta busca mejorar la organización de la información y la comunicación entre las áreas involucradas, contribuyendo a reducir errores y facilitar el seguimiento de los pedidos.

## Objetivo general

Desarrollar una propuesta de mejora del módulo de Comercialización que permita centralizar la información de los pedidos, consultar la disponibilidad de productos y coordinar las fechas de entrega de manera más eficiente.
